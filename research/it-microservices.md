# Каталог атомарных IT-микросервисов (РФ, mid-market)

**Назначение:** прайс- и продакшн-каталог атомарных IT/web-услуг для digital-агентств и веб-студий, работающих на российском рынке.

**Период цен:** 2024–2026 (среднерыночные ориентиры, Москва / крупные города, mid-market).

**Валюта:** RUB (без НДС, если не оговорено иначе).

**Принцип атомарности:** каждая позиция — отдельный продаваемый результат (не пакет вроде «сайт под ключ»). Пакеты собираются из атомов.

## Discovery / UX-исследования

### IT-001. CJM: карта пути клиента (базовая)

| Поле | Содержание |
|---|---|
| **Название** | CJM: карта пути клиента (базовая) |
| **Направление** | Discovery / UX |
| **Поднаправление** | CJM |
| **Тип** | Проектная |

**Результат**
- CJM в Miro/FigJam или PDF
- Этапы, touchpoints, боли и возможности
- Приоритизированный список UX-гипотез
- Краткие рекомендации по точкам роста

**Что входит**
- Брифинг и сбор артефактов (сайт, аналитика, скрипты)
- 1–2 воркшопа со стейкхолдерами
- Построение as-is CJM
- Выделение pain points и opportunities
- Презентация результатов

**Что не входит**
- Глубинные интервью с клиентами (отдельный атом)
- Usability-тесты
- Редизайн экранов
- Внедрение рекомендаций в код

**Драйверы объёма**
- Число сегментов / персон
- Число каналов и touchpoints
- Доступность данных (Метрика, CRM)
- Кол-во стейкхолдеров на воркшопах

**Параметры оценки (диапазоны)**
- Сегменты: 1 / 2–3 / 4+
- Каналы: сайт only / сайт+офлайн+реклама / омниканал
- Глубина: as-is / as-is+to-be

**Трудозатраты, ч:** 16 / 40 / 80 (min / avg / max)

**Специалисты:** UX-исследователь, UX-дизайнер, аналитик (частично)

**Рыночная цена, ₽:** 40 000 / 90 000 / 180 000 (min / avg / max)

**Продаётся до:** «Нужен редизайн» / «сайт не продаёт»

**Продаётся после:** CJM + список гипотез + бриф на исследования/редизайн

**Нишевые особенности**

| Ниша | Специфика |
|---|---|
| Строительство / ремонт | Сложные сценарии выбора услуг, много стейкхолдеров |
| Недвижимость | Длинный цикл сделки, важны доверие и этапы воронки |
| Банкротство / юруслуги | Юридическая чувствительность формулировок и согласий |
| Медицина | Ограничения рекламы, акцент на ПДн и доверии |
| E-commerce | Объём SKU, фильтры, скорость каталога |
| B2B IT / SaaS | Сложные роли, демо-запросы, интеграции |
| Образование | Сезонность набора, много лендингов курсов |

| **Направление** | Discovery / UX |
| **Поднаправление** | Интервью |
| **Тип** | Проектная |

**Результат**
- Гайд интервью
- Записи/расшифровки (по согласию)
- Сводка инсайтов и цитат
- Обновлённые персоны или jobs-to-be-done

**Что входит**
- Рекрутинг критериев и скринер
- Гайд 45–60 мин
- Проведение N интервью
- Аффинити / тегирование
- Итоговый отчёт

**Что не входит**
- Рекрутинг-агентство и стимулы респондентам (обычно отдельно)
- CJM (отдельный атом)
- Usability-тесты прототипа
- Количественный опрос

**Драйверы объёма**
- Число интервью
- Сложность рекрутинга (B2B vs B2C)
- Нужны ли записи и стенограммы
- Число сегментов

**Параметры оценки (диапазоны)**
- Интервью: 5 / 8–10 / 15+
- Сегменты: 1 / 2 / 3+
- Формат: онлайн / смешанный

**Трудозатраты, ч:** 20 / 48 / 100 (min / avg / max)

**Специалисты:** UX-исследователь, рекрутер (опц.)

**Рыночная цена, ₽:** 25 000 / 60 000 / 120 000 (min / avg / max)

**Продаётся до:** «Хотим понять клиентов»

**Продаётся после:** Отчёт + инсайты + рекомендации к CJM/прототипу

**Нишевые особенности**

| Ниша | Специфика |
|---|---|
| B2B IT / SaaS | Сложнее рекрутинг ЛПР, длиннее цикл |
| Медицина | Этические ограничения, согласия |
| Банкротство / юруслуги | Чувствительные темы — осторожный гайд |
| E-commerce | Фокус на выборе и checkout |
| Недвижимость | Длинный цикл, семья как ЛПР |
| Образование | Студент vs родитель — разные сегменты |
| Строительство | Смесь DIY и подрядчиков |
