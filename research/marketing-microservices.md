### M-001. Сбор и кластеризация семантического ядра

| Поле | Содержание |
|---|---|
| **Название** | Сбор и кластеризация семантического ядра |
| **Направление** | SEO |
| **Поднаправление** | Семантика |
| **Тип** | Проектная |

**Результат**
- Готовое семантическое ядро в таблице
- Кластеры с интентами
- Приоритизация по частотности и конкурентности
- Карта запросов → посадочные

**Что входит**
- Парсинг Wordstat/KeyCollector/Keys.so
- Чистка мусора и дублей
- Кластеризация (soft/hard)
- Разметка коммерч./инфо
- Выгрузка XLSX/Google Sheets

**Что не входит**
- Написание ТЗ на тексты
- Внутренняя перелинковка
- Технический аудит
- Закупка ссылок

**Драйверы объёма**
- Число запросов / кластеров
- Кол-во регионов
- Глубина ниши (узкая/широкая)
- Наличие конкурентов в ТОП-10

**Параметры оценки (диапазоны)**
- Объём ядра: 50–200 / 200–1000 / 1000–5000+ запросов
- Регионы: 1 / 2–5 / 10+
- Источники: Wordstat only / +Keys.so+конкуренты

**Трудозатраты, ч:** 8 / 24 / 60 (min / avg / max)

**Специалисты:** SEO-специалист, Junior SEO (парсинг)

**Рыночная цена, ₽:** 10 000 / 35 000 / 80 000 (min / avg / max)

**Продаётся до:** Список услуг / «нужен SEO»

**Продаётся после:** Ядро + карта посадочных + бриф на контент

**Нишевые особенности**

| Ниша | Специфика |
|---|---|
| Строительство / ремонт | Много гео- и коммерческих модификаторов («под ключ», районы) |
| Недвижимость | ЖК/районы/тип сделки — отдельные кластеры |
| Банкротство / юруслуги | Высокая юридическая чувствительность формулировок |
| Медицина | Ограничения рекламы мед. услуг — акцент на инфо-запросы |
| E-commerce | Категории + бренды + long-tail SKU |
| B2B IT / SaaS | Узкие B2B-формулировки, низкая частотность |
| Образование | Сезонность набора + курсы/программы |

## Приложение B. Методика ценообразования

1. **База:** клиентская ставка часа mid-market Москва × трудозатраты (см. `hourly-rates-rf.md`).
2. **Корректировки:** сложность ниши (+10–40% для medicine/bankruptcy/compliance), срочность (+20–50%), мультирегион/мультибренд.
3. **Медиа и сабс:** не входят в цену атома, фиксируются отдельно в договоре.
4. **Min/Avg/Max:** min — узкий бриф/типовой сайт; avg — стандарт mid-market; max — крупный контур, ecom/мультирегион, высокая экспертность.
