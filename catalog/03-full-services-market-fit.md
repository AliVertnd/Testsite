# Полноценные услуги для Impro (не атомы) — взгляд с рынка

**Задача:** какие **цельные продукты** продавать на витрине, а не микроуслуги.  
**Опора:** рынок РФ 2025–2026 + сайт Impro (`infoimpro.ru`: Performance, Контент, Стратегия, Веб/MarTech, Брендинг, ИИ) + кейсы (медицина, образование, банкротство, e-com, B2B, боты/CRM).

Комплексы из атомов — позже. Здесь — **названия услуг, как их покупает клиент**.

## Высокий fit — добавить в витрину (приоритет)

### 1. Сквозная аналитика под ключ
**Почему:** отдельный дорогой продукт у Soldi, Impecco, Dragons’Lab, Accent и др.; у вас ROMI — ядро обещания.  
**Клиент покупает:** «видеть от клика до денег в CRM».  
**Ориентир рынка:** от ~40–80к разово / проект 100–400к+.

### 2. Внедрение CRM (amoCRM / Bitrix24) под продажи
**Почему:** рынок продаёт как самостоятельную услугу (не «интеграция формы»); кейсы Impro уже про CRM.  
**Клиент покупает:** воронка, статусы, автоматизации, обучение команды.  
**Ориентир:** 75–400к+ (без лицензий).

### 3. Посадочные / лендинги под рекламу (Landing for Performance)
**Почему:** связка «Директ без нормальной посадки» — главный слив; у вас Next.js + performance.  
**Клиент покупает:** 1–N лендингов под кампании, не «сайт компании».  
**Ориентир:** 80–350к за лендинг mid-market.

### 4. CRO — оптимизация конверсии
**Почему:** продают performance-агентства как отдельную линию (гипотезы, A/B, UX посадочных).  
**Клиент покупает:** рост CR при том же трафике.  
**Ориентир:** аудит 40–120к · ведение 40–150к/мес.

### 5. GEO / продвижение в нейросетях
**Почему:** отдельная витринная линия 2025–2026 (Pixel Plus, Digital Geeks, ФОНИИ…); стыкуется с вашим блоком ИИ + SEO-смежным спросом.  
**Клиент покупает:** «нас цитирует ChatGPT / Алиса».  
**Ориентир:** аудит 40–150к · ведение 60–250к+/мес.

### 6. AI SEO (рядом с GEO или внутри «Поиск»)
**Почему:** рынок уже выносит отдельно от классического SEO.  
**Клиент покупает:** готовность контента/сайта к AI-выдаче.

### 7. Fractional CMO / маркетинг-директор на part-time
**Почему:** сильный тренд для SMB/mid; вы уже «партнёр, не подрядчик» на About.  
**Клиент покупает:** стратегию + контроль подрядчиков + KPI, без фуллтайм CMO.  
**Ориентир РФ boutique:** от ~80–250к/мес.

### 8. Сопровождение роста (Growth retainer)
**Почему:** рынок упаковывает «реклама + аналитика + гипотезы + правки сайта» в один абонемент.  
**Клиент покупает:** ежемесячный рост CPL/ROMI, а не часы контекстолога.  
**Ориентир:** 80–300к+/мес + медиа.

### 9. Отдел продаж + скрипты + регламент в CRM
**Почему:** у вас консалтинг + MarTech; рынок (и кейс «конвейер прибыли» / банкротство) бьёт в связку маркетинг↔продажи.  
**Клиент покупает:** не только лиды, а конверсию лида в оплату.

### 10. Отраслевые решения (vertical products)
**Почему:** кейсы уже есть — рынок платит за «для клиник / для юрфирм / для детсадов», не за абстрактный performance.  
Примеры продуктов:
- Impro для клиник (запись, бот, CRM, реклама)
- Impro для банкротства / юрсетей
- Impro для образования / детсадов
- Impro для e-com / локального ритейла

## Средний fit — взять вторым эшелоном

| Услуга | Зачем рынку | Комментарий для Impro |
|---|---|---|
| **Классическое SEO-сопровождение** | Стабильный ретейнер | Не флагман; апселл к performance / GEO |
| **SERM / управление репутацией** | Юристы, клиники, застройщики | Сильный upsell к вашим нишам |
| **Digital PR** | Экспертность + GEO-авторитет | Не чистое PR-агентство, а PR-for-growth |
| **Retention / CRM-маркетинг** (email, триггеры) | Дожим базы | После сквозной и CRM |
| **Telegram Ads / Авито** | Каналы leadgen в РФ | Доп. каналы в performance |
| **Техподдержка сайта / SLA** | После сдачи Next.js | Удержание клиента |
| **Партнёрка / white-label** для студий и консультантов | У вас есть `/partnership` | Отдельный B2B-продукт |
| **Обучение команды клиента** | Консалтинг-агентства продают | Workshops после аудита |
| **ABM / B2B leadgen** | SaaS и B2B в кейсах | Узкий, но маржинальный продукт |
| **Продуктовый маркетинг / launch** | Блок Стратегия/GTM | Именовать явно: «Запуск продукта» |

## Низкий fit — не вести как ядро

| Услуга | Почему мимо |
|---|---|
| Классический офлайн / ТВ / наружка full-service | Не ваш стек |
| Тяжёлый enterprise 1С/ERP | Другой рынок интеграторов |
| Чистый motion/кинопродакшн | Дорогой штат, не ядро |
| Мобильные приложения «с нуля» как основной продукт | В кейсах есть, но не центр бизнес-модели |
| Маркетплейсы WB/Ozon full-cycle | Отдельная экспертиза; только если появится команда |
| Big4-стратегия на полгода без внедрения | Против вашего «исполняемая стратегия» |

## Как это выглядит как витрина Impro (черновик меню)

Не атомы — **позиции каталога услуг**:

1. Маркетинг-аудит / диагностика ROMI  
2. Performance (Директ / VK / Telegram)  
3. Сквозная аналитика  
4. CRO  
5. Сайт / лендинги под рост  
6. Внедрение CRM + автоматизация продаж  
7. Боты и AI-ассистенты  
8. GEO / AI SEO  
9. Стратегия и GTM / Fractional CMO  
10. SMM и контент  
11. Брендинг  
12. SERM / Digital PR  
13. Отраслевые пакеты (клиники, юр, образование, e-com)  
14. Сопровождение роста (retainer)  
15. Партнёрская программа  

Пункты 3, 4, 6, 8, 9, 13, 14 — то, чего рынку не хватает в вашей текущей «шестёрке блоков», и что лучше всего стыкуется с вами.
