# Модель себестоимости микроуслуг Impro (РФ)

## Формула

```
Себестоимость = hours × blend_rate × 0.85 × (1 + PM_share)
Impro price   = себестоимость / (1 − целевая_маржа)
                с коррекцией к рыночному коридору
```

| Тир | Целевая маржа | Логика |
|---|---:|---|
| Min | 30% | T&M / понятный объём |
| Avg | 38% | Фикс. scope (основной прайс) |
| Premium | 45% | Сложные ниши / стратегия / rush |

Efficiency **0.85** — шаблоны, инструменты, повторное использование.  
PM_share **10–15%** от производственной себестоимости.

## margin_risk=YES

Рыночный avg **ниже** себестоимости Impro. Типично для демпинга фриланса/регионов на IT-атомах.  
**Не ориентироваться на рыночный floor** — продавать от Impro avg.
