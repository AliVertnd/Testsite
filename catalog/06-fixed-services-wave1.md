## Параметры калькулятора (общие)

Для любой FIX-услуги менеджер снимает:

1. Размер / сложность (страницы, кампании, пользователей CRM…)  
2. Ниша (коэффициент позже)  
3. Срочность (+0 / +20% rush)  
4. Доступы готовы? (если нет — + discovery)

Формула в калькуляторе:

```
цена = tier_price[S|M|L]
      × niche_coef (по умолчанию 1.0)
      × rush_coef
      + sum(options)
```
