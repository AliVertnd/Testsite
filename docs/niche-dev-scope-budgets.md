# Итог модели + границы ответственности + бюджеты ниши (девелопмент / модульные / ремонт)

**Статус:** рабочая фиксация под нишу  
**Ниша сейчас:** девелопмент · модульные дома · ремонт (и смежное строительство)

---

## 0. Итог модели (вашими словами — фиксируем)

1. **Холодка:** адаптивное предложение от триггера компании/ЛПР.  
2. **Два контура оплаты:**  
   - **К1** — крупный проект: **% и/или бюджет-конверт** на действие/период  
   - **К2** — **подписка** на определённый функционал (FN / OX)  
3. В **оба** контура закладываем **креатив + консультационно-аналитический слой** → сверхмаржа и качество результата.  
4. Направления: **маркетинг · IT (+автоматизация) · коммерциализация**.  
5. Дальше — жёстко понять: **что берём / не берём**, и из чего складывается бюджет в нише.

---

## 1. Три направления: что это в нише

| Направление | Смысл в девелопменте / модульных / ремонте |
|---|---|
| **Маркетинг** | Спрос: смысл ЖК/продукта, Директ/Авито/Циан/SEO/контент, прогрев, репутация |
| **IT + автоматизация** | Сайт/квиз/лендинг корпуса, CRM, коллтрекинг, интеграции с классифайдами, роботы, дашборд |
| **Коммерциализация** | Стык маркетинг↔продажи: квалификация лида, регламент ОП, скрипты, SLA ответа, обучение ОП **в границах**, юнит-экономика сделки |

Креатив + аналитика/консалтинг = **не отдельная «опция»**, а обязательный слой внутри каждого контура (см. §3).

## 2. Что берём / не берём (плотно)

Легенда: **ДА** · **ДА в границах** · **НЕТ** · **ПОЗЖЕ / партнёр**

### 2.1. Маркетинг

| Функция | Статус | Комментарий для ниши |
|---|---|---|
| Performance (Директ, VK, Telegram, Авито) | **ДА** | Ядро ниши |
| SEO / AI SEO / гео | **ДА** | Дома/ремонт — длинный цикл, SEO важен |
| Посадочные, квизы, ТЗ на контент объектов | **ДА** | Вместе с IT или внутри маркетинга |
| Контент/SMM light | **ДА в границах** | Лимит единиц; не «студия 24/7» |
| Бренд-платформа / смысл ЖК или линейки домов | **ДА** | Высокая маржа, консалтинг |
| Охватный OOH / ТВ / федеральный медиабаинг | **ПОЗЖЕ / партнёр** | Можем стратегию+бриф; закупку — с media-партнёром |
| Съёмка «кино» / полный продакшн ролика | **ДА в границах** | Бриф+продюсирование; тяжёлый продакшн — партнёр или отдельная строка |
| Работа с брокерами/АН как канал | **ДА в границах** | Материалы, офферы, регламент лидов; не управление сетью АН |
| Классифайды (Циан/Авито) ведение | **ДА** | Критично для модульных/ремонта |

### 2.2. IT + автоматизация

| Функция | Статус | Комментарий |
|---|---|---|
| Лендинги / квизы / доработка сайта | **ДА** | |
| CRM (amo/Bitrix): воронки, роботы, гигиена | **ДА** | Ключ коммерциализации |
| Коллтрекинг, сквозная, дашборд собственнику | **ДА** | |
| Интеграции сайт↔CRM↔телефония↔классифайды | **ДА** | |
| Чат-боты / AI-ассистент квалификации | **ДА** | |
| Битрикс24 «внедрение с нуля» enterprise | **ДА в границах** | Типовой контур; тяжёлый кастом — оценка отдельно |
| Разработка своего мобильного приложения | **НЕТ** (сейчас) | Партнёр |
| 1С / ERP / банковские интеграции | **НЕТ** / партнёр | Вне ядра |
| Хостинг/инфра «как DevOps 24/7» | **ДА в границах** | Только SLA light сайта |

### 2.3. Коммерциализация (включая ваш пример про обучение ОП)

| Функция | Статус | Граница |
|---|---|---|
| Диагностика воронки лид→договор | **ДА** | |
| Проектирование статусов CRM + регламент | **ДА** | |
| Скрипты / playbooks под нишу (возражения «дорого/ипотека/сроки») | **ДА** | |
| SLA первого ответа, контроль скорости | **ДА** | Вместе с IT |
| **Обучение существующего отдела продаж** | **ДА в границах** | См. блок ниже ★ |
| Совместные разборы звонков (выборка) | **ДА в границах** | N звонков/мес, не весь пол |
| Мотивация/KPI продавцов (схема) | **ДА в границах** | Рекомендации; внедрение с HR клиента |
| Найм / увольнение продавцов | **НЕТ** | Можем профиль вакансии и интервью light |
| Быть «РОПом full-time» / сидеть на планёрках каждый день | **НЕТ** | Fractional: 1–2 сессии/нед в подписке |
| Полевые продажи / показы объектов за клиента | **НЕТ** | |
| Юридическое сопровождение ДДУ/договоров подряда | **НЕТ** | Партнёр-юрист |
| Ценообразование лотов / смета ремонта «как ГИП» | **НЕТ** | Консалтинг по офферу — да; инженерия — нет |
| Управление стройкой / прорабами | **НЕТ** | |

#### ★ Обучение существующего ОП — решение

**Берём**, потому что без этого в нише маркетинг сгорает (лиды дорогие, ОП не закрывает).  
Но это **не бесконечный тренинг-центр**.

| Входит (платно, явно) | Не входит |
|---|---|
| Диагностика навыков по звонкам/сделкам | Полная замена РОПа |
| Серия воркшопов (например 4×2ч) + методичка | Ежедневный коучинг каждого продавца |
| Тренинг под новую воронку/оффер/квиз | Выездные показы |
| Онбординг ОП в CRM (совместно с IT) | Аттестации «как корпоративный университет» |
| Ежемес. разбор 5–10 звонков в подписке Scale | |

**Упаковка:** отдельная FN или модуль `FN-SALES-ENABLE` внутри коммерциализации.  
В пилоте — почти всегда нужен light-модуль, иначе К1/К2 по маркетингу бессмысленны.

## 3. Креатив + консультационно-аналитический слой (сверхмаржа)

В **каждом** контуре (К1 и К2) обязательная доля:

| Слой | Зачем | Как закладывать в бюджет |
|---|---|---|
| **Консалтинг / аналитика** | Юнит-экономика, CPL→CAC→договор, гипотезы, приоритизация | 15–25% работы Impro |
| **Креатив / смысл** | Оффер, УТП ЖК/дома/ремонта, креативы РК, ТЗ | 10–20% работы Impro |
| **Execution** | Каналы, IT, регламенты | 55–75% работы Impro |

Клиенту: «вы платите не только за клики, а за систему, которая считает и говорит что делать».  
Внутренне: это и есть сверхмаржа относительно чистого performance-подряда.

## 4. Два контура: из чего складывается бюджет

### К1 — Проект / период (бюджет или %)

```
КОНВЕРТ КЛИЕНТА
├── Media (Директ, Авито, Циан, посевы…)     50–70%
├── Production (съёмка, дизайн heavy…)       5–15%   (если нужно)
├── Работа Impro (FN + креатив + аналитика)  25–40%  ← фиксировали ~35% на пилот
└── Reserve                                  5–10%
```

Или **% от результата** (сделки/выручка атрибуции) + нижний фикс — отдельно согласовывать юр. и атрибуцию (в нише цикл длинный → осторожно).

### К2 — Подписка на функционал

```
ПОДПИСКА / мес = сумма FN
├── Маркетинг FN…
├── IT/Auto FN…
├── Коммерциализация FN… (часто + enablement ОП)
└── внутри каждой FN уже заложены аналитика+креатив light
Media — всегда отдельно.
```

## 5. Ниша: ориентиры рынка (чтобы собирать конверты)

| Ниша | CPL ориентир | Особенности |
|---|---|---|
| Застройщик / ЖК | часто 3–15к+ за лид; ДРР девелоперов ~2–5% выручки | Долгий цикл, ипотека, брокеры, классифайды |
| Модульные / дома под ключ | заявка часто 1.5–8к | Директ+Авито+SEO; важны квиз и прогрев |
| Ремонт | 2–6к заявка, ниша «перегрета» | Жёсткая квалификация, SERM, быстрый SLA ОП |

Крупные застройщики могут иметь media десятки млн/мес — вам туда через enterprise-трек.  
Холодка + К1/К2 сейчас = **региональный девелопер / модульщик / ремонт mid**.

## 6. Сборки бюджетов по направлениям и связкам

Цифры — **ориентиры для ниши mid** (не Москва-гигант). Работа Impro; media сверху.

### 6.1. Только маркетинг

| Контур | Состав | Работа Impro | Media ориентир |
|---|---|---|---|
| К2 Start | LEAD + PERF(S) + ANALYTICS(S) | **~180к/мес** | 150–400к |
| К2 Growth | + SEO + CONTENT | **~350к/мес** | 300–800к |
| К1 Пилот 60д | Конверт под лиды ЖК/домов | **35%** от конверта | Конверт 1.5–3м → Impro ~0.5–1м |

### 6.2. Только IT + автоматизация

| Контур | Состав | Цена |
|---|---|---|
| К2 Start | WEB+SUPPORT | **~90к/мес** |
| К2 Growth | + интеграции + CRM light | **~200к/мес** |
| К1 Проект | Квиз+лендинг+CRM+коллтрекинг «под ключ» | **250–600к** разовый (типовой mid) |

### 6.3. Только коммерциализация

| Контур | Состав | Цена |
|---|---|---|
| К2 | FUNNEL + CRM-процессы + enablement light | **~150–250к/мес** |
| К1 | Диагностика воронки + скрипты + обучение ОП (пакет) | **180–350к** проект |

### 6.4. Маркетинг + IT (частая связка)

Без продаж IT чинит сайт, маркетинг льёт — ОП сливает. Связка обязательна почти всегда.

| Контур | Сборка | Работа Impro |
|---|---|---|
| К2 | OX-MKT Start + OX-IT Start | **~270к/мес** + media |
| К2 | OX-MKT Growth + IT Growth | **~550к/мес** + media |
| К1 Пилот | Media + Impro 35% на PERF+WEB+ANALYTICS+квиз | Конверт **2–4м** / 60д |

### 6.5. Коммерциализация + IT ★

Именно про ваш вопрос «обучение ОП» + CRM.

| Контур | Сборка | Зачем |
|---|---|---|
| К2 | SALES-FUNNEL + SALES-CRM + ENABLE light + IT CRM/интеграции | ОП умеет + система не разваливается |
| Цена | **~220–350к/мес** | |
| К1 | Внедрение воронки + обучение 4 сессии + дашборд | **300–500к** проект |

### 6.6. Полная коммерциализация (маркетинг + продажи + IT) — лицо A

| Контур | Сборка | Работа Impro | Media |
|---|---|---|---|
| К2 OX-COM Core | MKT Start + Sales + CRM | **~280–350к/мес** | 200–500к |
| К2 OX-COM Full | MKT Growth + Sales(M) + IT Start | **~550–650к/мес** | 400–1.0м |
| К1 Пилот Serious | Конверт 3–8м на 90д: спрос+воронка+IT+enablement | **~32–35%** | остальное media/prod |

**Фраза клиенту (модульные/ремонт):**  
«Конверт 2 млн на 60 дней: ~700к — наша ответственность (стратегия, креатив, Директ/Авито, квиз, CRM, обучение ОП на новую воронку). ~1.3м — медиа. На выходе — CPL, % квалификации, договоры и решение: подписка OX-COM или следующий конверт.»

## 7. Адаптация по триггерам (холодка → какой контур)

| Триггер в нише | Куда ведём | Минимальный набор |
|---|---|---|
| Вакансия маркетолога/CMO | К1 пилот → К2 OX-COM | Функция вместо найма |
| «Дорогой лид / мало договоров» | К1 или К2: маркетинг+коммерция | Обязательно enablement ОП |
| «Сайт/CRM хаос» | IT + коммерция | Квиз+CRM+SLA |
| «Запуск нового ЖК / линейки домов» | К1 конверт | Смысл+креатив+performance+IT |
| «Нужен только Директ» | К2 узкий или B | Можно, но upsell коммерции |
| «Научите ОП» отдельно | К1 пакет enablement | Лучше связка с CRM |

## 8. Открытые решения (нужны ваши да/нет)

Чтобы добить матрицу «берём/не берём»:

1. **Обучение ОП** — согласны с формулой «ДА в границах» (воркшопы + разбор звонков), без роли РОПа?  
2. **Брокеры/АН** — берём методичку и офферы или хотите и мотивационные схемы для брокеров?  
3. **Циан/Авито** — ведение кабинетов сами или только стратегия?  
4. **Съёмка объектов** — всегда партнёр или есть своя продакшн-возможность?  
5. По нише фокус ближайших 10 холодных: **больше ремонт / модульные / застройщик**?

После ответов соберу: (а) one-pager границ для ниши, (б) 3 готовых конверта К1 и 3 подписки К2 под девелопмент/модуль/ремонт для КП холодки.
