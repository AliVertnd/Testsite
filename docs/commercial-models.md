# Коммерческие модели Impro

**Статус:** черновик под стратегическое партнёрство  
**Связь:** локомотив `LOC-002` · план v2

---

## Иерархия (как продаём)

```
Спринт «Архитектура вывода» (фикс, вход)
        ↓
Выбор модели партнёрства
        ├── 1. Общий маркетинговый бюджет (тендер)  ← приоритет
        ├── 2. % + бюджет
        └── 3. Фикс-подписка (AOR) + бюджет
```

---

## Модель 1 — Общий маркетинговый бюджет (тендер)

**Для кого:** вывод линейки, крупный запуск, ребрендинг, «нужен один ответственный».

**Суть:** клиент утверждает **один конверт** на период. Impro — генеральный подрядчик маркетинга: проектирует, распределяет, производит (или управляет подрядчиками), контролирует KPI, перераспределяет внутри конверта.

### Структура бюджета (пример строк)

| Статья | Пример доли | Комментарий |
|---|---:|---|
| Research / стратегия | 5–10% | часто уже закрыто спринтом |
| Креатив и продакшн | 20–35% | ролики, дизайн, контент |
| Media / performance | 35–55% | закупка + ведение |
| Digital product (сайт/лендинги/CRM) | 5–15% | под запуск |
| PR / спецпроекты | 0–15% | по задаче |
| Agency fee / управление | **?** | % или фикс — утвердить |
| Резерв | 5–10% | contingency |

### Договорная логика

- Рамочный договор партнёрства  
- Приложение: бюджетный конверт + KPI + этапы  
- Акты по этапам / месяцам внутри конверта  
- Прозрачный отчёт: план-факт по статьям + ROMI

### Плюсы для вас

- Высокий чек, длинный цикл  
- Контроль всей цепочки (не «кусок Директа»)  
- Естественный upsell внутри бюджета  
- Соответствует образу стратегического партнёра

## Модель 2 — % + бюджет

**Суть:** медиа/продакшн = бюджет клиента; Impro = % от бюджета и/или % от результата (лиды, выручка).

| Вариант | Формула | Риск |
|---|---|---|
| % от медиа | 10–20% от закупки | классика |
| % от результата | X ₽/лид или % от атриб. выручки | спор по атрибуции |
| Гибрид | пониженный % медиа + бонус за KPI | предпочтительнее чистого % |

Юридически: KPI как **целевой показатель**, не гарантия (как в SEO-договоре).

---

## Модель 3 — Фикс-подписка + бюджет

**Суть:** ежемесячный retainer за партнёрство (стратегия, координация, приоритет команды) + отдельные бюджеты кампаний.

| Retainer (ориентир) | Что внутри |
|---|---|
| 150–400к+/мес | стратег + аккаунт + контроль подрядчиков + планёрки + ROMI-отчёт |
| Бюджеты | медиа/продакшн отдельно, через Impro или напрямую |

Близко к Fractional CMO / AOR.

---

## Что на витрине vs что в переговорах

| Витрина | Переговоры |
|---|---|
| Спринт «Архитектура вывода» | Модель 1 как основной путь |
| Фикс-пакеты (аудит, лендинг…) | Для коротких задач и SMB |
| Не выставлять «SEO от 40к» как лицо бренда | Можно как элемент внутри бюджета |
