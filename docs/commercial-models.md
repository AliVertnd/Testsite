# Коммерческие модели Impro

**Статус:** v2 — после ревизии локомотива  
**Локомотив:** `LOC-003` Пилотный конверт (не платный план)

---

## Лестница (как есть и куда идём)

```
Химия / бриф
  → Пилотный конверт (LOC-003)           ★ первый контакт к идеалу
      → Большой конверт: бюджет + результат   ★ идеал
      → Partner Retainer (часы/задачи)        ★ текущая реальность
      → % + бюджет
      → Фикс-пакеты
```

Идеал и текущая практика **сосуществуют**. Локомотив учит клиента модели «бюджет + результат» на маленьком конверте.

---

## Модель Ideal — Бюджет + результат (конверт)

Клиент утверждает потолок. Impro само решает состав работ ради результата.  
Прозрачность: план-факт по статьям и ROMI, без микроменеджмента задач.

**Вход в неё:** пилот → расширение конверта.  
**Не вход:** продажа roadmap за фикс.

---

## Модель Now — Partner Retainer (фикс-подписка на часы)

Как вы работаете сейчас: подписка → задачи.

| Как не упаковывать | Как упаковать |
|---|---|
| «Часы специалистов» | Команда / приоритет / партнёрский retainer |
| Биржа тикетов | Еженедельный приоритет + стратегия light |
| Только execution | Часы стратегии + execution + короткий ROMI-отчёт |

Прайс: фикс/мес за пакет часов (например 40 / 80 / 120) + правило перерасхода.  
Апселл: «накопленный бэклог выгоднее закрыть пилотным конвертом».

---

## Модель % + бюджет

Media/production отдельно; Impro = % от бюджета и/или бонус за KPI.  
KPI юридически = целевые показатели.

---

## Модель фикс-пакеты

Аудиты, SEO этап 1, лендинг, CRM… — короткий scope.  
Не лицо стратегического партнёра, но нужны в каталоге и Bitrix.

---

## Пилот → идеал (зачёт)

При переходе в большой конверт: **100% стоимости работы Impro в пилоте** зачитывается (как договорились).  
Media в зачёт обычно не идёт.
