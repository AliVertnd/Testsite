## 2. Что такое fit_A (простыми словами)

`fit_A` — это **оценка «насколько эта компания похожа на клиента для партнёрства»**, а не для разового SEO.

Примеры сигналов «высокий fit_A»:
- ищут CMO / руководителя маркетинга  
- есть бюджет больше, чем на один канал  
- собственник/CEO в контуре решения  
- боль «нет системы», не «поправьте объявления»  

Примеры «низкий fit_A» (скорее B):
- нужен только SEO или только Директ  
- говорит только junior-маркетолог  
- бюджет крошечный  

**Порог 70** значил: «если оценка высокая — в КП не предлагаем кусочек, предлагаем пилот».  
Раз непонятно и нет данных — **пока без жёсткого числа**. Правило мягче:

> Если в M1 видим партнёрский потенциал — КП = пилот.  
> Если узкий запрос — КП = кусочек (B).  
> Сомневаемся — пилот light / nurture, не SEO «в лоб» как лицо.

## 3. Главный вопрос: мы на верном пути? Яндекс и «Guinness» через холодку?

### Короткий ответ

| Цель | Холодка M0–M3 как у вас | Верный путь? |
|---|---|---|
| Mid-market партнёрство / OX-COM / пилот → конверт | **Да, один из лучших входов** | ✅ верный |
| Контракт класса Guinness (вывод линейки крупного бренда) | **Почти никогда не с холодки по вакансии** | ⚠ другой канал |
| «Сотрудничество с Яндексом» как статус/контракт площадки | **Не через холодку клиентам** | ❌ другая система |

---

### 3.1. Сотрудничество с Яндексом — что это обычно

Часто путают два разных смысла:

**A. Вы — агентство-партнёр Яндекса** (сертификация, кабинет, статус, доступ к поддержке, иногда лиды от площадки)  
Путь: объём рекламы клиентов, экзамены/сертификация специалистов, заявка в партнёрскую программу, compliance.  
**Холодка по вакансиям компаний тут ни при чём.**

**B. Вы ведёте рекламу клиента в Яндексе** (Директ как FN-MKT-PERF)  
Путь: ваш пилот/OX → клиент даёт бюджет → вы крутите Директ.  
Это **не «контракт с Яндексом»**, а работа **на площадке Яндекса** в рамках клиента.  
Холодка как раз может привести к такому.

Если цель — статус партнёра Яндекса: отдельный трек (сертификация + портфель бюджетов), параллельно холодке.

---

### 3.2. Контракт «как Guinness» — как входят на рынке

Крупный бренд / вывод линейки / тендер на маркетинг обычно приходит через:

| Канал входа | Частота на крупном бренде |
|---|---|
| Тендер / RFP / питч | ★★★★★ |
| Рекомендация / личный контакт ЛПР | ★★★★ |
| Holding / сеть агентств | ★★★★ |
| Уже были подрядчиком → выросли в AOR | ★★★ |
| Кейс + PR / отраслевые рейтинги | ★★★ |
| **Холодка по вакансии CMO** | ★ редко |

Холодка по вакансии хорошо бьёт в:
- mid-market  
- founder-led  
- компанию **между CMO**  
- растущий бизнес без отдела  

Она **слабо** бьёт в:
- глобальный/федеральный бренд с procurement  
- «утвердили спецлинейку на совете — ищем генподрядчика» (там тендер и shortlist)

**Вывод:** система холодки — верный путь к **вашему A на mid-market**.  
Путь к Guinness-классу — **параллельный**: кейсы с mid → отраслевой питч/тендер/сеть, не «та же холодка масштабом».

---

### 3.3. Как холодка всё же связана с «большими» контрактами

Правильная длинная дуга:

```
Холодка → пилоты mid-market → OX-COM / конверты
  → сильные кейсы (+ интервью клиентов)
  → рейтинги / PR / рекомендации
  → shortlist тендеров и крупных запусков
  → Guinness-класс
```

Холодка = **фабрика кейсов и доказательств**, не прямой телефон в Guinness.

Интервью с клиентами после пилота — критичны: без них нечем идти в тендер.

## 4. На верном ли мы пути? (итог)

| Слой | Вердикт |
|---|---|
| Хотим быть партнёрами, не подрядом | ✅ модель A/B + FN это поддерживает |
| Холодка как канал | ✅ для mid-market A |
| Пилот 35% + FN | ✅ рыночно здраво |
| OX как этап к партнёрству | ✅ если north_star живой |
| «Через эту же холодку сразу Яндекс-партнёрка и Guinness» | ❌ ожидание неверное |
| Холодка → кейсы → тендеры/крупные бренды | ✅ верная длинная дуга |

**Мы на верном пути**, если цель ближайшего горизонта =  
*стабильный вход в mid-market партнёрства и сбор кейсов*.  

Если ждать, что M0–M3 сам по себе принесёт контракт уровня Guinness или статус у Яндекса — путь нужно **разделить на 2–3 канала**, не ломать холодку.

## 5. Что делаем дальше (без лишних развилок)

1. Цены OX — ориентир ±, пилот 35% — зафиксирован  
2. Состав пилота — гибкий по триггеру
