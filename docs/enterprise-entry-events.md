# Выход на крупные контракты (Guinness-класс): каналы и мероприятия

**Связь:** холодка = mid-market A · этот документ = параллельный трек на крупные бренды / тендеры / статус площадок  
**Не путать:** «контракт с брендом» ≠ «партнёрка Яндекса»

---

## 1. Как на рынке реально входят в крупные контракты

По убыванию частоты для брендов уровня «вывод линейки / генподряд маркетинга»:

| # | Канал входа | Что это | Когда срабатывает |
|---|---|---|---|
| 1 | **Тендер / RFP / питч** | Закупки или бренд объявляет отбор, shortlist 3–7 агентств | Есть кейсы + аккредитация + иногда NewBiz/закупки |
| 2 | **Рекомендация / warm intro** | ЛПР или советник приводит вас | Сильнейший канал; строится годами + мероприятия |
| 3 | **Уже были подрядчиком → выросли** | Сначала кусок/проект, потом AOR | Классика; у вас = B→A или пилот→конверт, но на крупном дольше |
| 4 | **Holding / сеть / субподряд** | Крупная сеть зовёт как execution или niche-partner | Нужны отношения с holding и узкая сила |
| 5 | **Рейтинги / премии / PR кейсов** | Попадаете в shortlist «кого позвать» | Нужны измеримые кейсы + публикации |
| 6 | **Мероприятия / спикерство** | Знакомство с бренд-маркетологами, CMO, закупками | Не продажа со сцены — вход в сеть |
| 7 | **Партнёрки площадок** (Яндекс и др.) | Статус → иногда лиды/доверие | Отдельный трек, не замена тендеру |
| 8 | Холодка по вакансии | Редко на федеральном бренде | Ваш основной канал для **mid**, не для Guinness |

**Итог:** на Guinness-класс выход = **тендер + сеть + кейсы**.  
Мероприятия — топливо для сети и спикерского капитала, редко прямой «подписанный контракт в тот же день».

## 2. Карта трёх треков Impro (чтобы не смешивать)

```
Трек 1 — ХОЛОДКА (уже проектируем)
  mid-market → пилот → OX/конверт → кейсы

Трек 2 — КРУПНЫЕ КОНТРАКТЫ
  target accounts → warm intro / тендер → питч → генподряд / годовой бюджет

Трек 3 — ПЛОЩАДКИ (Яндекс и др.)
  сертификация → статус → доверие + иногда лиды
```

Кейсы из трека 1 кормят трек 2.  
Трек 3 усиливает доверие в 1 и 2, но сам Guinness не приносит.

## 3. Трек 2 по шагам (крупный контракт)

### Шаг A — Target list (10–30 аккаунтов)
Не «все бренды», а узкий список:
- ниша, где у вас будет кейс (после холодки)
- тип задачи: вывод линейки / репозиционирование / digitalгенподряд digital
- есть CMO / бренд-директор / директор по маркетингу как роль

Карточка аккаунта: боли, триггеры, кто ЛПР, кто влияет, текущие агентства, тендеры в прошлом.

### Шаг B — Войти в shortlist
Параллельно:
1. Warm intro через узлы сети (клиенты, консультанты, организаторы, HRD, другие агентства)  
2. Подача в тендеры (NewBiz, закупки клиента, приглашения)  
3. Спикерство / публикации → вас узнают до питча  

### Шаг C — Питч
Не прайс SEO. Питч =:
- понимание задачи бренда  
- архитектура вывода / коммерциализации  
- команда + RACI  
- бюджетный конверт и KPI  
- 1–2 релевантных кейса (хотя бы mid, честно упакованных)

### Шаг D — Контракт
Часто: пилотный проект / первая кампания → потом год.  
Реже: сразу годовой AOR без пробы.

## 4. Мероприятия: зачем и какие

### Зачем идти (честно)

| Цель на мероприятии | Реально? |
|---|---|
| Подписать Guinness в тот же день | Почти нет |
| Познакомиться с CMO / бренд-директорами | Да |
| Найти «узлы сети» для intro | Да ★ |
| Стать спикером → статус | Да (нужен кейс) |
| Увидеть, кто в shortlist крупных | Да |
| Найти партнёров (продакшн, media) | Да |
| Лиды mid-market | Иногда, не главная цель НРФ |

**Правило:** мероприятие = **канал отношений и shortlist**, не канал «закрытой сделки».

### Типы площадок

| Тип | Примеры / класс | Для чего Impro |
|---|---|---|
| Индустриальные рекламные | **НРФ** (Москва, нояб.), Red Apple / связанные дни | Сеть, статус, крупные игроки |
| Digital / интерактив | отраслевые дни АРИР, digital-конференции | Performance + MarTech |
| Отраслевые клиентские | медицина / образование / retail / FMCG-форумы | Прямой ЛПР из ниши кейса |
| Локальные бизнес | Новосибирск / регион business clubs | Mid-market + тёплые intro |
| Площадки вендоров | события Яндекс Реклама, VK, МТС и т.п. | Статус, продукт, непрямой бренд |

НРФ’10 ориентир: **10–13 ноября 2026**, Москва ([advertisingforum.ru](https://advertisingforum.ru/)) — стратегические дни + digital + креатив; там же экосистемы вроде Яндекс Реклама как участники программы.

### Как отрабатывать мероприятие (операционка)

**До**
- Список 15 целевых людей/компаний  
- Цель: 5 содержательных разговоров + 2 intro  
- Одно предложение про Impro (партнёр коммерциализации, не «делаем Директ»)  
- 1 кейс / one-pager в кармане  

**На**
- Не стенд ради стенда на первом году, если нет бюджета — лучше **спикер / участник + вечерки**  
- Просить intro у тех, с кем уже поговорили  
- Фиксировать контакты в Bitrix в тот же день (`track=enterprise`, источник=`event:NRF`)

**После (72 часа)**
- Персональное follow-up не «было приятно», а «по вашей задаче X — гипотеза / материал»  
- Если mid — можно предложить пилот  
- Если крупный бренд — предложить **разбор / chemistry**, не сразу конверт

## 5. Партнёрка Яндекса (отдельно)

| Что | Путь |
|---|---|
| Сертификация специалистов | Экзамены / обучение Директ и смежное |
| Статус агентства | Объёмы клиентов, заявка, правила программы |
| Эффект | Бейдж доверия, иногда лиды, поддержка |
| Не даёт | Автоматический контракт Guinness |

Имеет смысл **после** того, как в портфеле уже крутятся бюджеты с пилотов/OX (трек 1).

## 6. Что делать Impro по кварталам (практично)

### Сейчас (пока нет пачки кейсов)
1. Трек 1: холодка → пилоты → кейсы + интервью клиентов  
2. Собрать **15 узлов сети** (кого просить intro)  
3. Выбрать **1–2 мероприятия** в год (НРФ + 1 отраслевое под нишу)  
4. Не жечь бюджет на стенд без цели  

### Когда есть 2–3 сильных кейса
1. Target list 10–20 крупных/upper-mid  
2. Подача в тендеры / NewBiz  
3. Спикерство на отраслевом или НРФ (кейс-сессия)  
4. Параллельно — заявка в партнёрку Яндекса, если тянете объёмы  

### Формат «Guinness» в продаже
Не холодное «возьмите нас генподрядчиком», а:
- chemistry meeting  
- paid discovery / пилот волны (если бренд допускает)  
- или полноценный питч по RFP

## 7. Связь с вашей системой документов

| Трек | Локомотив / офер |
|---|---|
| 1 Холодка | Пилотный конверт + FN |
| 2 Крупные | Питч «Архитектура вывода / коммерциализация» + конверт/%; вход через тендер/intro |
| 3 Площадки | Не офер клиенту, а инфраструктура доверия |

Мероприятия в Bitrix = источник лида `event`, дальше может уйти в M1/M2 **той же** воронки, но с тегом `enterprise` и другим entry_offer (питч, не холодный пилот 1.5м).

---

## 8. Короткий ответ на ваш вопрос

**На такие контракты выход:**  
тендер + warm intro + кейсы (+ иногда рост из малого подрядного куска).  

**Мероприятия:** да, нужны — как машина знакомств, intro и статуса, особенно НРФ и отраслевые форумы ниши.  
Они **не заменяют** холодку и **не заменяют** тендер; они питают shortlist.

Холодка остаётся верным путём для mid-market и фабрики кейсов, без которых на Guinness-класс почти не зовут.
