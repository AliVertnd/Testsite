# Методология каталога микроуслуг Impro

## Цель

Единый каталог атомарных услуг агентства (маркетинг + IT + консалтинг) для рынка РФ: оценка, продажа, сборка комплексов, контроль маржи.

## Что считаем атомом

Атом = работа с измеримым результатом, которую можно продать и оценить отдельно.

| Не атом (пакет) | Атомы |
|---|---|
| SEO-продвижение | Семантика, техаудит, ТЗ, статья, ссылка, Метрика |
| Сайт под ключ | Дизайн страницы, вёрстка, форма, CRM, QA |
| Маркетинговая стратегия | Аудит, позиционирование, UE, roadmap каналов |

## Карточка микроуслуги (поля)

1. **Название**  
2. **Направление** / **Поднаправление**  
3. **Тип** — разовая / ежемесячная / проектная  
4. **Результат** — что получает клиент  
5. **Что входит**  
6. **Что не входит** — жёсткие границы  
7. **От чего зависит объём**  
8. **Параметры оценки** — что выясняет менеджер (диапазоны)  
9. **Трудоёмкость** — min / avg / max часов  
10. **Специалисты**  
11. **Рыночная стоимость** — min / avg / max ₽ (РФ)  
12. **Себестоимость Impro** — из ставок часа  
13. **Рекомендуемая цена Impro** — min / avg / premium  
14. **Что продаётся до / после**  
15. **Особенности ниш**  

## Этапы работ

### Этап 1 — полный список

Собрать 100–300 атомов без цен. Источники: услуги 100+ агентств (маркетинг, IT-студии, консалтинг), разложение пакетов на атомы.

### Этап 2 — карточки

Заполнить границы, драйверы, параметры оценки, ниши.

### Этап 3 — рынок

Только цена атома. Источники: сайты агентств, рейтинги, тендеры, КП, собственная практика.

### Этап 4 — нормативы и себестоимость

Часы × операционные ставки Impro (junior-leverage, efficiency 0.85, PM-буфер). См. `catalog/cost-model.md`.

### Этап 5 — комплексы

Комплекс = список ID атомов. Цена = сумма. Никаких отдельных «тарифов SEO» без расшифровки.

## Роли менеджера при оценке

1. Выбрать атомы / шаблон комплекса  
2. Снять параметры оценки (объём, регионы, CMS, доступы…)  
3. Выбрать сценарий часов min/avg/max  
4. Умножить на нишевой коэффициент  
5. Выставить Impro avg или premium  
6. При `margin_risk=YES` не цепляться за рыночный демпинг
