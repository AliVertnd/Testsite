# Сходится ли всё к стратегическому партнёрству?

**Ответ: да — если держать дисциплину трека A.**  
Документы складываются в одну лестницу. Риск не в модели, а в сползании в «ещё один аутсорс-подряд» на практике.

---

## Одна лестница (как задумано)

```
Лицо бренда / холодка
  → не «сделаем SEO», а пилот ФУНКЦИИ коммерциализации
        ↓
Формат 1: бюджет/% на действие (локомотив)
  → клиент платит за ответственность FN, не за часы тикетов
        ↓
Decision (PM)
  → Формат 2: OX-COM / OX-MKT…  ИЛИ  большой конверт / % / партнёрский договор
        ↓
Цель A: стратегическое партнёрство
  (% · партнёрская модель · единый годовой бюджет)
  контуры: маркетинг + продажи + IT
```

Направление B (кусочки) — **не лицо**, а полка и мост.  
Так и записано в `agency-offer-architecture.md`.

---

## Как куски документов стыкуются

| Слой | Документ | Роль для партнёрства |
|---|---|---|
| Цель | A/B архитектура, company-profile | North star = A, не «закрыть канал» |
| Вход | Локомотив + холодка M0–M3 | Платный пилот функции, не бесплатный аудит-подряд |
| Язык денег | FN + OX | «Ответственность = цена», не «часы биржи» |
| Два формата | commercial-models | Конверт/% и подписка — оболочки одной цели |
| Рынок | market-peers | Категория «отдел», не «агентство Директа» |
| Производство | атомы / FIX | Топливо внутри FN, не витрина для A-клиента |

**Подписка OX ≠ отказ от партнёрства.**  
У КРИК/Lead.Media подписка часто и есть потолок («ведём маркетинг»).  
У вас подписка — **этап**, north star в карточке сделки = % / годовой конверт / партнёрский договор.

## Где может разъехаться (и как не дать)

| Угроза «стать подрядом» | Защита в модели |
|---|---|
| M2 продаёт SEO вместо пилота | Трек A + Locomotive agent |
| OX-MKT продаёте как «пакет каналов» | В КП всегда FN + лид функции + путь к A |
| Клиент на часах навсегда | Partner Retainer = мост, review → OX-COM |
| Витрина = 308 атомов | Атомы внутрь; наружу A = пилот/OX-COM |
| Рынок тянет к 80к «2 канала» | Не опускать Start; не копировать Lead.Media face |
| «Гарантия лидов» как у аутсорсеров | KPI целевые, образ партнёра по ROMI/контуру |

---

## Короткий тест «мы партнёры или подряд?»

В любой сделке/КП должно быть да на 4 пункта:

1. Берём **контур** (хотя бы маркетинг+стык с продажами), не один канал  
2. Есть **лид функции** (FN-MKT-LEAD), не только execution  
3. В договоре/strategy card прописан **north star A**  
4. Деньги за **ответственность FN/конверт**, не за «закрытые тикеты»

Если нет — это B (нормально), но не называем стратегическим партнёрством.

## Итог

| Вопрос | Ответ |
|---|---|
| Документы противоречат цели «не подряд»? | Нет |
| OX-подписка убивает партнёрство? | Нет, если это этап к A |
| Рыночные аутсорсеры = то же самое? | Полка похожа; цель и FN/COM у вас жёстче |
| Всё складывается? | **Да** |

Дальше критично не новые концепции, а **дисциплина внедрения**: поля `track` / `north_star` в Bitrix и запрет агентам M2 продавать B на A-fit.
