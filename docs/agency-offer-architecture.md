# Архитектура предложений Impro (зафиксировано)

**Статус:** опорная модель агентства  
**Дата фиксации:** 2026-09-07  
**Смысл:** мы строим реальность агентства — функционал и возможности предложений, не абстрактный прайс.

---

## Два направления (и только два)

```
                    IMPRO
                      │
        ┌─────────────┴─────────────┐
        │                           │
   НАПРАВЛЕНИЕ A              НАПРАВЛЕНИЕ B
 Стратегическое               Комплекс задач
 партнёрство                  «по кусочкам»
        │                           │
   Большой функционал         Ограниченный scope
   коммерциализации           в подписанной модели
   (маркетинг + продажи + IT) (SEO, Директ, сайт…)
        │                           │
   Цель: % / партнёрская      Цель: закрыть задачу
   модель / единый годовой    клиенту и/или вырасти в A
   бюджет
```

Оба направления легитимны.  
**A — куда хотим дойти в любом серьёзном клиенте.**  
**B — как продаём и зарабатываем сейчас и для тех, кому A рано.**

---

## Направление A — Стратегическое партнёрство

### Суть

Берём на себя **большой функционал коммерциализации проекта** по контурам:

| Контур | Что означает «взять на себя» |
|---|---|
| **Маркетинг** | Смысл, спрос, каналы, бренд, контент, ROMI |
| **Продажи** | Воронка, CRM-процессы, скрипты, стык маркетинг↔продажи |
| **IT / MarTech** | Сайт/лендинги, интеграции, аналитика, автоматизация, боты/ИИ |

Это не «ведём Директ», а **внешний контур коммерциализации** (или его существенная часть).

### Целевые коммерческие формы (к чему приходим)

Любая из трёх = успех направления A:

1. **% модель** (от бюджета / результата / выручки — уточняем по сделке)  
2. **Подписанная партнёрская модель** (AOR / внешний отдел / retainer функции)  
3. **Единый годовой (или периодный) бюджет-конверт** — бюджет + результат, Impro решает состав работ  

### Как входим в A

Не продаём сразу «годовой бюджет» с холодки.

```
Триггер (напр. вакансия CMO) / тёплый лид
  → пилот функции (LOC-003) или сильный проектный вход
  → расширение ответственности по контурам
  → фиксация % / партнёрства / годового конверта
```

Логика входа: `offers/locomotive-logic-cold.md`  
Продукт входа: `offers/locomotive-pilot-envelope.md`

### Для кого A

- Mid-market и переходные (рост, дыра в CMO, смена агентства)  
- Новые продуктовые/инвест-линии  
- Компании, готовые отдать контур, а не один канал  
- Не цель холодки на закрытый enterprise-AOR (там тендер/рекомендации)

## Направление B — Комплекс задач «по кусочкам»

### Суть

Выполняем **ограниченный** набор работ в подписанной модели.  
Продажа через логику кусочков / пакетов: SEO, Директ, лендинг, CRM, аудит…

Клиент покупает понятный scope и фикс (или гибрид внутри куска).

### Зачем B нужно

1. Cash-flow и загрузка сейчас  
2. Клиенты, которым рано/не нужно A  
3. **Мост в A** — кусочки → доверие → партнёрство  
4. Витрина компетенций (атомы → пакеты → калькулятор)

### Как устроено B

```
Атомы (308) → полноценные услуги / FIX-пакеты → комплексы
Продажа: фикс → позже гибрид → реже %
Bitrix: каталог + калькуляторы (после утверждения)
```

Каталог: `catalog/` · калькулятор: `calculator/`

### Граница B

B **не** позиционируем как лицо стратегического партнёра.  
На витрине для A-сегмента лицо = партнёрство/пилот функции.  
B — отдельная полка: «нужен SEO / сайт / Директ — вот пакеты».

---

## Связь A и B

| Ситуация | Что продаём |
|---|---|
| Холодка по вакансии CMO / «нужен отдел» | A (пилот → партнёрство) |
| «Нужен SEO / лендинг / Директ» | B |
| Клиент B стабильно докупает куски | Предлагаем переход в A |
| Клиент A просит точечно вне конверта | Доп. как B или внутри конверта |
| Сейчас живём на часах/задачах | Partner Retainer = **мост** (формально ближе к B, цель — вырастить в A) |

```
B ──мост──► A
часы / SEO / проекты     партнёрство / % / годовой бюджет
```

## Что это значит для сборки агентства сейчас

Мы проектируем **два продукта агентства**, не один прайс:

| Слой | Направление A | Направление B |
|---|---|---|
| Оффер | Партнёрство / пилот функции / конверт | FIX, комплексы, атомы |
| Продажи | Триггеры, холодка, ЛПР-собственник | Классические заявки «нужен SEO» |
| Производство | Кросс-контур: маркетинг+продажи+IT | Узкие команды по направлению |
| Договоры | Партнёрский / конверт / % | Фикс-scope (как SEO-договор) |
| Bitrix | Сделка типа «Партнёрство» + конверт | Каталог услуг + калькулятор |
| KPI агентства | Доля выручки из A, LTV | Маржа кусочков, конверсия B→A |

---

## Зафиксированные принципы

1. Цель в серьёзном клиенте — **дойти до A** (% / партнёрство / годовой бюджет).  
2. B — полноценное направление, не «стыдный временный режим».  
3. A = маркетинг **+ продажи + IT** как коммерциализация, не только performance.  
4. Локомотив холодки обслуживает **A**, не B.  
5. Каталог атомов/FIX обслуживает **B** и снабжает A исполнением внутри конверта.
