## 1. Кто мы

| Поле | Значение |
|---|---|
| Бренд | Impro Digital (`infoimpro.ru`) |
| Суть | Агентство **коммерциализации**: маркетинг + продажи + IT / автоматизация |
| Не суть | Агентство одного канала («только Директ / только SEO») |
| Цель в серьёзном клиенте | Стратегическое партнёрство: % · партнёрская модель · единый бюджет периода |
| Как зарабатываем сейчас | Кусочки и подписки + вход через пробу; cash-flow и мост в партнёрство |

**Одна фраза для рынка:**  
мы берём (или помогаем собрать) **контур превращения спроса в деньги** — от смысла и каналов до заявки в учёте и передачи в продажи.

**Три рабочих направления внутри:**

| Направление | Смысл |
|---|---|
| Маркетинг | Смысл, спрос, каналы, контент, репутация, ROMI |
| IT + автоматизация | Сайт/лендинги, CRM, интеграции, боты, аналитика, ИИ-контур |
| Коммерциализация | Стык маркетинг↔продажи: воронка, регламенты, скрипты, обучение ОП **в границах**, юнит-экономика сделки |

В **любой** серьёзной сборке закладываем слой **креатив / смысл** и слой **аналитика / консалтинг** — это маржа и качество, не «опция».

## 2. Клиент и сегменты

### 2.1. Направление A (лицо бренда, холодка, локомотив)

| Поле | Рабочая гипотеза (уточнять) |
|---|---|
| Кто | Mid: региональный застройщик, модульные дома, ремонт «под ключ», смежный B2C/B2B с чеком от ~150–300 тыс.+ |
| ЛПР | Собственник, CEO, коммерческий директор |
| Ситуация | Есть продукт/объект, но нет собранного контура «спрос → заявка → продажа»; или контур есть, но дорого / не закрывает |
| Деньги | Готовы к найму CMO/РОП **или** к рекламе от ~150–300 тыс./мес; «Директ за 40к» — не они |
| Покупают | Снятие ответственности за кусок коммерции, не «канал» |
| Страх | Ошибиться с подрядчиком; потерять сезон; нанять не того |

### 2.2. Направление B (полка, cash-flow)

Малый и mid, которым нужен SEO / Директ / лендинг / CRM light.  
Их **не** кормим локомотивом партнёрства. Мост: кусочек → доверие → A.

### 2.3. Не клиент локомотива A

Федеральный холдинг с тендером (другой трек) · «идеи бесплатно» · только баннеры · нет ЛПР · нет готовности к тестовой рекламе после входа.

### 2.4. Две психологии первого чека

| Покупка | Нормально «рискнуть» | Что сравнивают |
|---|---|---|
| Проверить подрядчика (канал) | 50–150 тыс. | Аудит Директа, лендинг |
| Проверить партнёра по коммерции | 180–350 тыс. **работы** + реклама отдельно | Найм + хаос 2–3 мес |
| Запуск / замена функции | 0,7–1,75 млн работы + медиа | ФОТ CMO/РОП + агентства |

Пакет «800 тыс. одной цифрой на агентство» для *проверки* часто тяжёл; для *запуска* — нормален, если реклама и работа разделены в голове ЛПР.

## 3. Два направления продаж

```
                    IMPRO
                      │
        ┌─────────────┴─────────────┐
        │                           │
   НАПРАВЛЕНИЕ A              НАПРАВЛЕНИЕ B
 Стратегическое               Комплекс задач
 партнёрство                  «по кусочкам»
        │                           │
   Маркетинг+продажи+IT       Ограниченный scope
        │                           │
   % / партнёрство /          Фикс / узкая подписка
   годовой бюджет             Мост в A
```

| | A | B |
|---|---|---|
| Суть | Контур коммерциализации | Ограниченный объём |
| Цель сделки | % · партнёрство · бюджет периода | Фикс (позже гибрид) |
| Вход | Пробный пакет / тестовый контур | SEO, Директ, сайт, CRM… |
| Лицо бренда | **Да** | Нет (полка) |
| KPI агентства | Доля выручки из A, LTV | Маржа кусочков, конверсия B→A |

**Правило витрины:** лицо = пробный пакет → ежемесячная коммерциализация.  
Фикс-пакеты — отдельная полка, не первый слайд для A-сегмента.

## 4. Иерархия сборки услуг (как всё связано)

Это **главная логика составления**. Клиенту продаём верх; внутри считаем низ.

```
УРОВЕНЬ 0  Повод / схема (вакансия, запуск, дорогой лид…)
                ↓
УРОВЕНЬ 1  Комплекс / оффер (что покупают: проба, OX-COM, FIX…)
                ↓
УРОВЕНЬ 2  Модуль / функция FN (зона ответственности + цена)
                ↓
УРОВЕНЬ 3  Атом (исполнение, смета, приёмка, договор)
```

| Уровень | Кто видит | Пример |
|---|---|---|
| 0 Повод | Менеджер, сайт-помощник | «Вакансия РОП на новый продукт» |
| 1 Оффер | Клиент в КП | «Пробный пакет на 60 дней под цель X» |
| 2 Функция | Клиент в таблице ответственности | Performance · Воронка продаж · Сайт |
| 3 Атом | Impro / приложение к договору | M-023 Настройка Директ; IT-039 форма→CRM |

**Цена комплекса ≠ отдельный прайс «из воздуха».**  
Цена = сумма функций (подписка) **или** доля/фикс работы внутри бюджетного пакета **или** сумма атомов (фикс-пакет / смета).

**Клиенту в КП:** комплекс + модули + (по желанию) приложение «состав» списком атомов — как прозрачность объёма, **не** построчный прайс 308 позиций.

## 5. Два формата денег

| | Формат 1 — Бюджет / доля на период | Формат 2 — Подписка / аутсорс |
|---|---|---|
| Клиент платит | Конверт или % | ₽/мес за комплекс функций |
| Impro отвечает | За результат периода; само решает состав | За постоянный контур |
| Когда | Пилот, запуск, сезон, квартал | «Маркетинг / IT / коммерциализация снаружи» |
| Локомотив | Пробный пакет = мини-формат 1 | После пробы часто → формат 2 |
| Сборка | Набор FN внутри конверта | Набор FN как ежемесячный комплекс |

Медиа и лицензии **почти всегда отдельно** (или отдельной статьёй внутри конверта — не как «гонорар Impro»).

### Сетка доли работы Impro (формат 1)

| Тип действия | Работа Impro от конверта | Минимум работы |
|---|---:|---:|
| Пилот (локомотив) | 30–40% (база **35%**) | от 250 тыс. |
| Performance-кампания | 15–25% | от 80 тыс. |
| Вывод продукта / линейки | 20–35% | от 350 тыс. |

## 6. Локомотив — пробный бюджетный пакет коммерциализации

**Код:** `LOC-PILOT`  
**Канон:** `offers/LOC-PILOT-canon.md`

### 6.1. Суть

Клиент утверждает **один бюджет на 30 / 60 / 90 дней** и **одну бизнес-цель**.  
Impro берёт ответственность за результат в рамках пакета: само решает состав (маркетинг / IT / стык с продажами).  
Внутри всегда: **аналитика + креатив/смысл + единый ответственный**.  
В конце — цифры и **встреча решения**: расширяем партнёрство или нет.

Это не аудит, не «план», не «настроим Директ».  
Это **мини-версия стратегического партнёрства**.

### 6.2. Ступени (ниша mid)

| Ступень | Срок | Конверт | Impro ≈35% | Когда |
|---|---|---:|---:|---|
| Проба (Smoke) | 30 дн | **800 000** | 280 000 | Узкий контур / быстрая проба |
| Основная (Standard) | 60 дн | **2 000 000** | 700 000 | Основной вход холодки |
| Крупная (Serious) | 90 дн | **5 000 000** | 1 750 000 | Запуск / замена функции |

Коридоры: 0,6–1,2 · 1,5–3,0 · 3,5–8,0 млн.  
Мин. работа Impro: **250 000**.  
Перезачёт: **100%** работы Impro в следующий контракт при старте ≤30 дней после решения.

### 6.3. Формула конверта

```
ПАКЕТ = РЕКЛАМА + ПРОИЗВОДСТВО + РАБОТА IMPRO + ЗАПАС

РАБОТА IMPRO = 0.35 × ПАКЕТ     (коридор 0.30–0.40)
ЗАПАС        = 0.05–0.10 × ПАКЕТ
ПРОИЗВОДСТВО = 0–0.15 × ПАКЕТ   (съёмка / тяжёлый дизайн)
РЕКЛАМА      = остаток
```

**Вариант B (для доверия на входе):** реклама на счёте клиента; Impro — фикс за пробу (те же ступени по сумме работы).

### 6.4. Внутренняя раскладка 35%

| Слой | Доля от работы Impro |
|---|---:|
| Аналитика / консалтинг | 20% |
| Креатив / смысл | 15% |
| Исполнение модулей | 55% |
| Управление | 10% |

### 6.5. Модули пробы (выбираем 1–3 сверх каркаса)

| Модуль | Когда | Что |
|---|---|---|
| Платный спрос | Нужен спрос | Директ / VK / Telegram / Авито |
| SEO | Длинный цикл | Тех+контент приоритеты, ТЗ, контроль |
| Классифайды | Модуль/ремонт | Авито/Циан — стратегия ± ведение |
| Посадка | Слабая конверсия | Лендинг/квиз, формы, трекинг |
| CRM light | Лиды теряются | Воронка, роботы light, коллтрекинг |
| Стык с ОП | ОП не закрывает | Регламент, скрипты, 2–4 воркшопа, разбор звонков |

**Правило ниши:** платный трафик + есть ОП → стык с ОП почти обязателен.

### 6.6. Не входит в пробу

Гарантия N договоров штрафом · РОП full-time · найм/увольнение · показы объектов · стройка · юристы ДДУ · 1С/ERP · федеральный медиабаинг / кино без отдельной строки · всё вне одной цели.

### 6.7. Развитие локомотива (рабочая гипотеза доверия)

Для сценария «проверить подрядчика» обсуждается отдельный вход **L0 «Тестовый контур»** (~180–350 тыс. работы Impro + реклама отдельно, 2–4 недели, все три слоя спектром, 100% перезачёт).  
Полный пакет 2 / 5 млн — когда ясна цель «запуск / замена функции», а не «аудит доверия».

## 12. Логика поводов → предложение

Холодка: **адаптивное КП от триггера**, не один шаблон всем.

### 12.1. Карта выбора оффера

| Вопрос | Если да → |
|---|---|
| Есть повод T1–T6 и бюджет ≥ пробы? | LOC-PILOT |
| Уже работали / нужен постоянный контур? | OX-* |
| Просит один канал без системы? | FIX / FN |
| Enterprise / тендер? | Не холодный пилот; отдельный трек |
| Только «идеи / аудит / план»? | Либо узкое исполнение, либо отказ |

Мягко: **A-fit → пилот**, **B-fit → кусочек**.

### 12.2. Схемы поводов (логика)

#### T1. Вакансия маркетолога / CMO
Гипотеза: нет функции. Цель: закрыть маркетинг на 60–90 дн без найма.  
Сборка: смысл + спрос + аналитика + (ОП) стык. → OX-MKT / OX-COM.

#### T1б. Вакансия РОП / коммерческого по **новому продукту**
Гипотеза: продукт есть, коммерческого контура нет.  
Цель: первая повторяемая воронка / первые платящие / партнёры — **одна** цель.  
Сборка: **полная коммерциализация light** (смысл → спрос → посадка → CRM → регламент → обучение ОП).  
Не продаём: «нанять РОПа за вас».

#### T2. Дорогой лид / мало договоров
Сборка: спрос + CRM + стык с ОП. Без ОП проба обесценивается.

#### T3. Запуск ЖК / линейки
Смысл + креатив + спрос + посадка (+ классифайды). Обычно 90 дн, медиа крупной строкой.

#### T4. Хаос сайт / заявки / CRM
Посадка + CRM + SLA ответа. Медиа можно почти не трогать.

#### T5. «Проверить агентство»
Не полный 2 млн как «тест». Узкий показательный контур / L0 + перезачёт.

#### T6. Сезон / акция
Одна кампания end-to-end. После — серия или B.

#### T7. Смена агентства / сломан Директ
Если хотят систему → T2/T5. Если «перезапустите канал» → FIX-P02, не локомотив A.

#### T8. Слабые классифайды при живом продукте
Стратегия + ведение + креативы + CRM + скрипт квалификации.

#### T9. «Только SEO / только Директ»
Полка B. В КП одной строкой — следующий шаг в контур, если понадобится.

### 12.3. Алгоритм актуализации КП (10 минут)

1. Код оффера  
2. Ступень и модули по умолчанию из триггера  
3. Поджать по активам клиента (нет сайта → посадка; нет ОП → слабее enablement)  
4. Цифры в коридоре (не ниже мин. Impro)  
5. Цель человеческим языком  
6. 2–4 KPI-ориентира  
7. Явный next (OX / пакет / выход)  
8. Блок из калькулятора  

Подробно: `offers/kp-actualization.md`.

### 12.4. Состав КП по типу

| Блок | Проба | OX | FIX |
|---|---|---|---|
| Повод и цель | ★ | кратко | кратко |
| Зона ответственности | каркас+модули | список FN | объём пакета |
| Не входит | ★ | ★ | ★ |
| Деньги | конверт | ₽/мес | фикс |
| KPI | ориентиры | лёгкий регламент | результат поставки |
| Decision / next | обязателен | апселл | мост в пробу/OX |
| Зачёт | 100% Impro | — | иногда |

## 13. Границы ответственности (ниша)

Легенда: **ДА** · **ДА в границах** · **НЕТ** · **ПОЗЖЕ / партнёр**

### Маркетинг
Performance, SEO/AI SEO, посадочные/квизы, контент light, смысл ЖК/линейки, классифайды — **ДА**.  
OOH/ТВ/федеральный баинг — партнёр. Тяжёлое кино — партнёр или отдельная строка.

### IT
Лендинги, CRM amo/Bitrix, коллтрекинг, интеграции, боты/AI-квалификация — **ДА**.  
Своё мобильное приложение, 1С/ERP, DevOps 24/7 — **НЕТ** / партнёр / границы.

### Коммерциализация
Диагностика воронки, статусы CRM, скрипты, SLA ответа, обучение ОП (воркшопы + разбор звонков), мотивация-схема light — **ДА в границах**.  
Найм/увольнение, РОП full-time, показы объектов, ДДУ-юристы, смета как ГИП, стройка — **НЕТ**.

Полная матрица: `docs/niche-dev-scope-budgets.md`.

## 14. Ценообразование и маржа

### 14.1. Атом
Рынок min/avg/max → себестоимость (часы × ставки) → Impro min/avg/premium.  
При `margin_risk=YES` не цепляться за рыночный демпинг.

### 14.2. Фикс-пакет
`цена = tier[S|M|L] × ниша × срочность + опции`

### 14.3. Функция / OX
Сумма FN × ступень; медиа отдельно.

### 14.4. Пробный пакет
Impro = 35% конверта (мин. 250к); остальное media/prod/reserve.

### 14.5. Целевая маржа
В модели себестоимости заложен ориентир **~35–40%** на работе Impro (прямая маржа на услугах агентства).  
Перезачёт маржи теста в комплекс — сознательный жест доверия ради LTV.
