## Два направления предложений

### A — Стратегическое партнёрство (цель)

Берём большой функционал коммерциализации проекта.  
Целевые формы: **% · партнёрская модель · единый годовой/периодный бюджет**.

Вход: пилот функции / сильный проект → расширение контуров.

### B — Комплекс задач «по кусочкам»

Ограниченный scope в подписанной модели.  
Продажа кусками: SEO, Директ, сайт, CRM…  
Нужно для cash-flow, SMB и как **мост в A**.

## Локомотив

- Каталог FIX / атомы / калькулятор → обслуживают **B** (+ исполнение внутри A)
