## Эталонный проект (класс задач)

**Выведение новой продуктовой линейки** (пример: спецлинейка для новой ЦА):

1. Смысл и позиционирование  
2. Коммуникационная / креативная платформа  
3. Рекламные ролики и кампании  
4. Digital / performance / PR по архитектуре  
5. Контроль реализации внутри утверждённого маркетингового бюджета  

Горизонт: месяцы, не «настройка кабинета за неделю».

---

## 6 блоков компетенции (как слои партнёрства)

1. Performance  
2. Контент  
3. Стратегия  
4. Веб / MarTech  
5. Брендинг  
6. Внедрение ИИ  

В тендере блоки = **статьи бюджета и команды**, не отдельные «услуги с витрины».
