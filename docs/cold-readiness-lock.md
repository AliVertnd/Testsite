## 1. Итог, который фиксируем (решения)

### Кто мы
Стратегический партнёр по **коммерциализации**: маркетинг + продажи + IT.  
Не агентство одного канала.

### Два направления
| | A | B |
|---|---|---|
| Суть | Партнёрство / контур | Кусочки |
| Цель сделки | % · партнёрская модель · годовой бюджет | Фикс / узкий scope |
| Лицо бренда | **Да** | Нет (полка + мост) |

### Два формата денег (на одних FN)
1. **Бюджет / % на действие** — конверт, Impro решает состав  
2. **Подписка / аутсорс** — OX-* из функций FN  

### Локомотив холодки
**Пилотный конверт (формат 1)** = мини-версия партнёрства.  
Не бесплатный аудит. Не «идеи к вакансии». Не продажа плана.

Крючок: вакансия CMO/head → *функция на 60–90 дней вместо/на время найма*.

## 4. Порядок работ на ближайший цикл (холодка)

```
1. Утвердить этот итог (цены + правила)     ← вы
2. Собрать 5 артефактов раздела 3A         ← делаем в репо
3. Завести поля Bitrix + RAG-корпус        ← вы / внедрение
4. Прогнать 5–10 тестовых M0→M1→hook       ← вместе
5. Включить холодку на узкий ICP           ← вы
6. После 10 созвонов — калибровка FN/цен   ← вместе
```

### ICP на старт холодки (узкий)
- Выручка: уточнить ваш пол (ориентир mid-market)  
- Сигнал: вакансия CMO / руководитель маркетинга / «маркетолог с нуля»  
- ЛПР: собственник / CEO / коммерческий  
- Не брать: junior SMM-вакансии, микробизнес без бюджета на конверт
