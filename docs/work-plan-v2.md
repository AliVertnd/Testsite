## Что такое «фиксированная услуга» (рабочее определение)

**Фикс = клиент знает цену до старта** при заданных параметрах оценки.

| Включаем в фазу A | Не включаем (фазы B/C) |
|---|---|
| Разовые атомы (161 шт.) | Ежемесячное ведение без потолка объёма |
| Проектные атомы с параметрами (118 шт.) | «SEO от X ₽/мес» без расшифровки |
| Полноценные услуги = **сборка атомов + прайс-матрица** по параметрам | % от рекламного бюджета |
| Пакеты с жёстким scope («до 50 стр.», «до 500 запросов») | % от выручки / лидов |

**279 из 308 атомов** — кандидаты на фикс (разовая + проектная).  
**29 атомов** — подписочные (фаза B: фикс-база + переменная надбавка).

## Bitrix и калькуляторы (фаза E — подготовка)

**Сейчас:** проектирование логики, без переноса.

### Предлагаемая структура в Bitrix

```
Направление (SEO, Директ, IT…)
  └── Полноценная услуга (продаётся)
        ├── Модель цены: фикс / гибрид / %
        ├── Прайс-матрица (справочник параметров)
        └── Состав: связь M-N атомов (many-to-many)
              └── Атом (микроуслуга) — справочник, не продаётся напрямую
```

### Калькулятор в CRM (логика)

1. Менеджер выбирает **полноценную услугу**
2. Заполняет **параметры оценки** (форма)
3. Система подставляет tier → **фикс-цена**
4. Опционально: доп. атомы → **+ к сумме**
5. Вывод: цена клиенту, себестоимость, маржа, состав для договора

**Вопросы к заказчику:** см. блок «Bitrix» в подготовительных вопросах (обсуждение в чате).
