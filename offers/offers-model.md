## 1. Карта офферов

```
ХОЛОДКА / ТЁПЛЫЙ ЛИД
        │
        ├─ track A (партнёрский fit) ──► LOC-PILOT (Smoke/Standard/Serious)
        │                                      │
        │                                      ▼ decision
        │                         ┌────────────┼────────────┐
        │                         ▼            ▼            ▼
        │                      OX-*         большой К1     узкий B / выход
        │                   (подписка)      / % / партнёр
        │
        └─ track B (кусочки) ──────────► FIX / отдельный FN
                                               │
                                               ▼ при доверии
                                          LOC-PILOT или OX-Start
```

| Код | Тип | Контур | Когда продаём |
|---|---|---|---|
| **LOC-PILOT** | Локомотив К1 | Пилот 30–90д | Холодка A, вход в партнёрство |
| **OX-COM** | Подписка К2 | Коммерциализация | После пилота / тёплый A |
| **OX-MKT** | Подписка К2 | Маркетинг | После пилота / B→A мост |
| **OX-IT** | Подписка К2 | IT / MarTech | IT-дыра или добор к OX-MKT |
| **OX-AUTO** | Подписка К2 | Автоматизация | CRM/боты/ИИ контур |
| **K1-PERIOD** | Конверт периода | Квартал/год | Зрелый A-клиент |
| **K1-%** | % + бюджет | Партнёрство | Когда есть прозрачная база % |
| **FIX-*** | Фикс B | Узкий scope | «Нужен SEO/Директ/лендинг» |
| **RET-*** | Часы | Light-мост | Не готов к FN/OX; переводим дальше |
| **FN-*** | Функция | Стройка комплексов | Внутри OX / кастом КП |

**Правило витрины:** лицо бренда = LOC-PILOT → OX-COM. FIX не в первом слайде для A-сегмента.

## 2. Логика выбора оффера (M2)

| Вопрос | Если да → |
|---|---|
| Есть триггер T1–T6 и готовность к бюджету ≥ Smoke? | **LOC-PILOT** |
| Уже работали / пилот пройден / нужен постоянный контур? | **OX-*** |
| Просит один канал без ответственности за систему? | **FIX / FN** |
| Enterprise / тендер / партнёрский статус? | Не холодный LOC; `docs/enterprise-entry-events.md` |
| Только «идеи / аудит / план»? | Не продаём как лицо; либо Smoke с исполнением, либо отказ |

Мягкое правило: **A-fit → пилот**, **B-fit → кусочек**. Жёсткий порог score≥70 не фиксируем, пока нет калибровки M1.

## 3. Калькуляция по типам

| Оффер | Формула | Источник цифр |
|---|---|---|
| LOC-PILOT | `IMPRO = 0.35 × КОНВЕРТ` (мин. 250к) | `offers/loc-pilot-calc.json` |
| OX-* | прайс ступени Start/Growth/Scale | `catalog/functions-pricing.json` |
| K1-PERIOD | конверт периода × доля Impro 20–35% | индивидуально + канон доли |
| K1-% | % от согласованной базы + floor | договор |
| FIX | прайс пакета S/M/L | `catalog/06-fixed-services-wave1.md` |
| FN | сумма FN × ступень | `catalog/07-…` + JSON |
| RET | ставка × пакет часов | коммерческие модели |

Калькулятор UI: `calculator/index.html` (вкладки: функции, локомотив, фикс, атомы).

## 4. Состав КП по типу оффера

| Блок КП | LOC-PILOT | OX-* | FIX |
|---|---|---|---|
| Триггер / боль | ★ | кратко | кратко |
| Одна цель / зона ответственности | ★ | список FN | scope пакета |
| Не входит | ★ | ★ | ★ |
| Калькуляция | конверт | ₽/мес | фикс |
| KPI ориентиры | ★ | SLA light | результат пакета |
| Календарь / ритм | недели | месячный цикл | срок поставки |
| Decision / next | ★ обязателен | апселл ступени | мост в пилот/OX |
| Зачёт | 100% Impro | — | иногда в пилот |

- `offers/kp-templates/LOC-PILOT-kp.md`
- `offers/kp-templates/OX-generic-kp.md` (ниже по мере наполнения)
