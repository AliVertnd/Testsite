# Локомотив Impro v3: «Пилотный конверт»

**Код:** `LOC-003`  
**Статус:** рабочая гипотеза после ревизии рынка  
**Почему не v2:** «Архитектура вывода» = платный план. Рынок и ваше ощущение совпали: это слабый первый контакт.

---

## Что в реальности используют компании, которые потом дают «бюджет + результат»

Сводка практики (AOR / генподряд / крупный маркетинг-бюджет), РФ + международка:

| Первый контакт | Что это | Почему работает | Почему Impro |
|---|---|---|---|
| **Paid pilot 30–90 дней** | Реальное исполнение + один KPI + жёсткий срок | Клиент «прощупывает» команду в деле, не в презентации | ★ лучший матч к «бюджет + результат» |
| Проектный аудит / credentials pitch | Тендер, креативный питч, иногда pitch fee | Вход через закупки / бренд | Для крупных тендеров, не ежедневный локомотив |
| Точечный проект (лендинг, кампания, ролик) | Одна поставка | Audition через project work (AOR-питчи падают) | Ок как SMB / параллельный вход |
| Retainer на часы | «Подписка: делаете задачи» | Низкий риск, знакомо | **Ваша текущая реальность** |
| Платный «план / диагностика» | Отчёт без исполнения | Легко продать, плохо доказывает партнёра | ✗ не лицо бренда |

Вывод рынка: **клиенты всё чаще аудируют агентство через проект/пилот, а не через AOR-питч и не через оплату roadmap.**

---

## Идеальная модель vs локомотив

| | Идеал (куда целимся) | Локомотив (первый контакт) |
|---|---|---|
| Формула | **Бюджет + результат**, Impro само решает, что делать | То же, но **маленький конверт и короткий срок** |
| Горизонт | Квартал–год / вывод линейки | 30–90 дней |
| Риск клиента | Высокий | Ограничен потолком пилота |
| Что доказывает | Партнёрство | Что с вами можно так работать |

Локомотив = **мини-версия идеала**, не «продажа плана».

## Продукт: Пилотный конверт

### Pitch (черновик имени — обсудим)

> Выделяете тестовый маркетинговый бюджет на 30–90 дней.  
> Impro само определяет, что делать для результата по одной цели.  
> В конце — цифры, разбор и решение: расширяем конверт / идём в подписку / расходимся.

Рабочие варианты названия (выбрать):

1. **Пилотный конверт**  
2. **Пилот под результат**  
3. **Первая волна**  
4. **Тестовый бюджет**  
5. Ваше имя  

### Условия пилота

| Параметр | Правило |
|---|---|
| Цель | **Одна** бизнес-цель (лиды продукта X, запуск линейки light, ROMI канала Y…) |
| Конверт | Клиент утверждает потолок бюджета (media + production + работа Impro) |
| Свобода | Impro само распределяет внутри конверта — это и есть проба модели №1 |
| Срок | 30 / 60 / 90 дней |
| Результат | Исполнение + отчёт + decision meeting |
| Не входит | Обещание «гарантированных» лидов как в SLA-штрафах; KPI = целевые |

### Триггеры (адаптация цели пилота, не «глубины аудита»)

| Код | Ситуация клиента | Цель пилота |
|---|---|---|
| P1 | Новая линейка / продукт | Первая волна спроса / awareness+leads |
| P2 | Реклама есть, результата нет | Перезапуск одного контура под ROMI |
| P3 | Нужен один ответственный | 60–90 дней «как генподряд» на узком scope |
| P4 | Запуск сезона / акции | Одна кампания end-to-end |
| P5 | Хотим проверить Impro до большого бюджета | Любая одна цель + decision gate |

## Деньги: как брать в пилоте

Ближе к вашему «просто бюджет и результат»:

```
ПИЛОТНЫЙ КОНВЕРТ = одна сумма
  внутри (прозрачно для клиента, но без микроменеджмента):
    • media
    • production / креатив
    • работа Impro (стратегия + исполнение + контроль)
```

Два рабочих варианта тарификации пилота:

| Вариант | Как | Когда |
|---|---|---|
| **A. Один конверт** ★ | Клиент платит N ₽ «на пилот», Impro распределяет | Идеальный вход в модель «бюджет + результат» |
| **B. Конверт media + фикс Impro** | Media отдельно, Impro — фикс за пилот | Если закупки требуют разделения |

Ориентиры конверта (для обсуждения, не оферта):

| Пилот | Срок | Конверт порядка | Зачем |
|---|---|---:|---|
| Smoke | 30 дн | 400–800 тыс. | Быстрая проба химии |
| Standard | 60 дн | 1.2–3 млн | Нормальный decision quality |
| Serious | 90 дн | 3–8 млн+ | Почти мини-тендер |

Точные цифры зафиксируем, когда скажете типичный чек пилота / кейс.

**Зачёт:** если после пилота идёте в большой конверт — 100% «работы Impro» внутри пилота можно зачесть в следующий agency/конверт (как вы и сказали).

## Лестница сотрудничества (честная)

Идеал — не единственный путь. Вы уже работаете иначе — это нормально.

```
0. Химия / бриф (бесплатно, коротко)
        ↓
1. ЛОКОМОТИВ: Пилотный конверт          ← лицо бренда, путь к идеалу
        ↓
2a. Большой конверт (бюджет + результат) ← идеал
2b. Фикс-подписка на часы / задачи       ← текущая реальность
2c. % + бюджет
2d. Фикс-пакеты (аудит, лендинг, SEO…)   ← короткий scope
```

| Модель | Статус | Комментарий |
|---|---|---|
| Бюджет + результат (конверт) | **Цель** | Локомотив = её мини-версия |
| Фикс-подписка на часы | **Сейчас живёте** | Не стыдно; упаковать как «Partner Hours / Retainer» с приоритетом и отчётом |
| % + бюджет | Опция | Когда есть атрибуция |
| Фикс-пакеты | Опция | SMB и точечные задачи |
| Платный roadmap без исполнения | Не локомотив | Можно как этап *внутри* пилота, не как продукт |

### Подписка на часы — как не выглядеть «биржей»

Если пока так работаете, упаковка важнее сути:

- Название: **Partner Retainer** / «Стратегические часы» / «Команда на месяц»  
- Не «оплата часов», а **пакет приоритета**: стратегия + исполнение задач из бэклога  
- Внутри: лимит часов, SLA ответа, еженедельный приоритет, ROMI-отчёт  
- Апселл: «из retainer вырастаем в пилотный/полный конверт»

Это мост, не враг идеала.

## Связь с вашими ответами

1. **Fee:** идеально «бюджет и результат, сами решаем» → пилот именно так и устроен  
2. Мин. бюджет тендера — пока unknown → задаём через пилотные ступени Smoke/Standard/Serious  
3. Цены спринта — не нужны как локомотив  
4. Зачёт 100% — закладываем при переходе пилот → большой конверт  
5. Имя — точно другое → выбираем из списка выше  
6. Кейс есть — **нужен разбор** (без имён ок): что было входом, какой бюджет, чем закончилось
