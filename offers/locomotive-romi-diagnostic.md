# Локомотив Impro: «Диагностика ROMI»

**Код услуги:** `LOC-001`  
**Модель цены:** фиксированная (фаза A)  
**Тип:** разовый входной продукт → дорожная карта → продажа полноценных услуг / комплексов  
**Статус:** черновик v1 для согласования

---

## 1. Зачем локомотив

Нужен **один старт**, который:

1. Легко купить (фикс, понятный срок, понятный результат)  
2. Адаптируется под **триггер клиента** (боль)  
3. За один проект показывает **всю ширину Impro** (6 блоков)  
4. Естественно ведёт к следующему чеку (SEO / Директ / сайт / CRM / ИИ…)

Это не «бесплатный аудит» и не «стратегия на год».  
Это **платная диагностика роста** с приоритизированным планом на 90 дней.

---

## 2. Одно предложение (pitch)

> За фиксированную сумму за 10–15 рабочих дней разберём, где вы теряете ROMI: трафик, сайт, CRM, аналитика, позиционирование — и отдадим приоритетный план работ с оценкой эффекта и состава услуг Impro.

---

## 3. Триггеры → адаптация состава

Менеджер выбирает **1 главный триггер** (+ до 2 второстепенных).  
Базовый каркас один; «углубление» меняется.

| Код | Триггер клиента | Углубление (акцент) | Типичный next-sell |
|---|---|---|---|
| T1 | «Тратим на рекламу — лидов мало / дорого» | PPC-аудит + посадочные + аналитика | Директ/VK ведение, лендинг, CRO |
| T2 | «Сайт есть — заявок нет» | UX + CRO + SEO light | Лендинг / доработка сайта, SEO этап 1 |
| T3 | «Лиды есть — продажи проседают» | Воронка + CRM + скрипты | Внедрение CRM, регламенты продаж |
| T4 | «Не видим цифры / не верим отчётам» | Сквозная аналитика + Метрика + CRM | BI, сквозная, коллтрекинг |
| T5 | «Непонятно, чем отличаемся» | Позиционирование + конкуренты + оффер | Бренд-платформа, контент, PR |
| T6 | «Хотим ИИ / боимся отстать» | AI SEO / GEO + AI-процессы | AI SEO, GEO, боты, AI-ассистенты |
| T7 | «Запускаем продукт / новый рынок» | GTM light + каналы + юнит-экономика | GTM, медиаплан, лендинг+реклама |
| T8 | «Репутация / отзывы мешают» | SERM + бренд в поиске | SERM, PR, карточки карт |

**Правило:** триггер меняет **глубину одного блока**, не отменяет остальные.  
Клиент всё равно получает overview по всей цепочке — так мы доносим максимум о деятельности Impro.

---

## 4. Что входит (результат клиенту)

### Обязательный каркас (все tier)

1. Интервью с ЛПР (60–90 мин) + бриф  
2. Карта текущего пути: **канал → сайт → заявка → CRM → деньги**  
3. Экспресс-оценка 6 блоков Impro (балл + 1–2 инсайта на блок)  
4. Углублённый разбор по главному триггеру  
5. Топ-10 проблем с приоритетом (impact × effort)  
6. План на 90 дней: что делать сами / что с Impro  
7. Смета next-step (2–3 сценария: минимум / оптимум / максимум)  
8. Итоговая сессия 60 мин (разбор)

### Артефакты

- PDF-отчёт (15–25 стр. для M/L)  
- One-pager для ЛПР (1 стр.)  
- Таблица «проблема → услуга Impro → ориентир цены»  
- (Опционально) доступ к короткому дашборду «что измерять дальше»

## 6. Прайс-матрица (фикс)

Цены — **рабочий ориентир Impro** (не оферта). После ваших ответов зафиксируем.

| Tier | Для кого | Срок | Часы внутри (ориентир) | Цена клиенту |
|---|---|---|---:|---:|
| **S — Express** | Локальный бизнес, 1 продукт, 1–2 канала | 7–10 р.д. | 28–36 | **49 000 ₽** |
| **M — Standard** | Mid: несколько каналов, есть сайт+реклама | 10–15 р.д. | 45–60 | **89 000 ₽** |
| **L — Deep** | Сложная воронка / несколько направлений / сеть | 15–20 р.д. | 75–100 | **149 000 ₽** |

### Как выбирается tier

| Параметр | S | M | L |
|---|---|---|---|
| Выручка / бюджет на маркетинг | до ~300к/мес маркет. | 300к–1.5м | от 1.5м или сложный продукт |
| Каналы в работе | 1–2 | 3–4 | 5+ / omnichannel |
| Есть CRM | нет / примитив | есть | есть + интеграции |
| Углублений по триггеру | 1 | 1 + 1 light | 2 полных |
| Конкурентов в разборе | 3 | 5 | 7–10 |

### Себестоимость (черновик)

| Tier | Себест. ориентир | Маржа при цене выше |
|---|---:|---:|
| S | ~28–32к | ~35–40% |
| M | ~50–58к | ~35–40% |

## 7. Что не входит

- Внедрение рекомендаций

- Рекламный бюджет и лицензии  
- Гарантия роста лидов/продаж по итогам диагностики  
- Полная бренд-платформа / годовая стратегия (это отдельные услуги)

## 8. Логика продажи (скрипт коротко)

1. **Триггер** — «Что сейчас больнее всего?» → код T1–T8  
2. **Параметры** → tier S/M/L  
3. **Фикс в КП** + состав углубления  
4. **Диагностика** → отчёт  
5. **Итог-сессия** → выбор сценария next-step  
6. Переход в договор на услугу/комплекс (фикс / гибрид / %)

### Как доносим максимум о Impro

В отчёте каждый блок витрины = отдельная страница:

| Страница отчёта | Блок Impro | Next-sell |
|---|---|---|
| Performance | Директ/VK/Telegram | настройка / ведение |
| Контент | SMM / контент | стратегия + ведение |
| Стратегия | аудит / GTM / UE | стратегия / Fractional CMO |
| Веб/MarTech | сайт / CRM / боты | лендинг, CRM, интеграции |
| Брендинг | оффер / ToV | айдентика / платформа |
| ИИ | AI SEO / GEO / автоматизация | аудиты + внедрение |

Клиент уходит не с «SEO-аудитом», а с картой агентства под свою боль.
